## 📝 Descripció

**CalcMatCat** és una aplicació web intuïtiva i interactiva dissenyada per a docents i famílies. Permet generar automàticament fitxes d'exercicis matemàtics (sumes, restes, multiplicacions i divisions) personalitzades per a diferents nivells d'educació primària i exportar-les directament a format PDF a punt per imprimir.

L'objectiu principal és facilitar la creació de material didàctic de reforç o avaluable en qüestió de segons, adaptant la dificultat i el tipus d'operacions a les necessitats específiques de cada alumne.

---

## ✨ Característiques principals

- ⚡ **Generació instantània**: Operacions aleatòries configurables en un sol clic.
- 🎯 **Adaptable a diferents nivells**:
  - Triar el tipus d'operació (Sumes, Restes, Multiplicacions, Divisions o Mix).
  - Configuració del nombre de xifres i portades/dues línies.
  - Ajust del nombre total d'exercicis per full.
- 🖨️ **Exportació a PDF / Impressió**: Disseny adaptat per a impressió en A4, net i sense elements d'interfície superflus.
- 🔑 **Solucionari inclòs**: Opció per generar la fulla de solucions per a una correcció ràpida per part del mestre o auto-correcció de l'alumne.
- 🌐 **100% Client-Side**: No requereix cap servidor backend, funciona directament al navegador.
- 📱 **Disseny Responsive**: Interfície cuidada amb Tailwind CSS adaptada a ordinadors, tauletes i mòbils.

---

## 🚀 Tecnologies utilitzades

- **HTML5**: Estructura semàntica de la web.
- **Tailwind CSS**: Estilisme modern, àgil i adaptable (amb suport per a print media query).
- **JavaScript (ES6+)**: Lògica de generació d'operacions matemàtiques aleatòries i manipulació del DOM.
