Configura la teva Gemini API Key

DictaCAT utilitza els models de Google Gemini per redactar els dictats i generar l'àudio TTS en català. La teva clau es guarda només localment al teu navegador.

Com aconseguir una API Key de Gemini

És 100% gratuïta i només et cal un compte de Google

  1. 1

    Accedeix a Google AI Studio

    Entra a la plataforma oficial per a desenvolupadors de Google:

    aistudio.google.com/app/apikey
  2. 2

    Inicia sessió

    Entra amb el teu compte personal de Google (Gmail) o de centre educatiu.

  3. 3

    Crea la teva clau

    Fes clic al botó blava "Create API key" i tria un projecte per defecte.

  4. 4

    Copia la clau a DictaCAT

    Copia el text generat (comença per AIzaSy...) i enganxa'l al camp de configuració de DictaCAT.
